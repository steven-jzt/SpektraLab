【为编通 GLib 做的本地处理（需知情）】
  GLib 2.86.5 用 Meson 构建，上游要求从 wrapdb 取 zlib/pcre2 补丁包，而 wrapdb 在本机不可达。
  处理方式：
    - zlib 1.3.1 与 pcre2 10.44 用 CMake 自行构建并安装到同一前缀
    - libffi 用 meson 从 gitlab 拉取（pin 83d0cfd）
    - proxy-libintl 放入 glib/subprojects/proxy-libintl（pin 33934de）
    - 补造 libz.a（CMake 只产出 libzlibstatic.a）
  另外 engine/setup-codecs.ps1 中 libpng-1.6.59 的哈希被换为 GitHub tag 归档的哈希
  （sourceforge 在本网络只返回 HTML 中间页）。

【运行】
  双击 spektralab.exe；命令行用 spektralab-cli.cmd status
  目录名可以是中文（已在干净中文目录实测）。
  但不要放在带 Everyone:(DENY)(DC) 的目录里：WebView2 建环境会失败，
  错误码在 os error 5 / 0x800700AA / 0x8000FFFF 之间漂移。
  本机 C:\Users\steve\Desktop\胶片模拟程序 就带这条继承 ACL。

【已知限制】
  contrast_mask 仍被引擎拒绝（macOS 版同样隐藏）；Nikon HE/HE* 不支持；
  Intel Arc 上 fma residual 与 Metal 参考差 1e-11 量级（上游声明过的边界）。
